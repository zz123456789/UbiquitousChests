# Ubiquitous Chests 1.0.2

Minecraft 1.20.1 · Forge · Java 17 · Install on both client and server.

- First public release on the mod hosting platforms.
- Random single-chest underground structures, discoverable with `/locate`.
- Configurable generation probability, depth range, biome and dimension blacklists.
- Configurable weighted loot entries, quantities and roll counts.
- Optional JEI + JER dungeon loot pages, synchronized with server loot data.
- Original project material is now MIT licensed; license texts are included in the JAR.
- Added public source repository, publishing documentation and project artwork.

Gameplay is unchanged from 1.0.1. Replace the old JAR; do not install both versions.
